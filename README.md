Store Debt Management System

A web application built with Flask and MySQL to help small shop owners manage customer debts, payments, and outstanding balances.

Overview

This project aims to simplify debt tracking for small businesses by providing a centralized interface for managing customer financial records.

Features

- Manage customer debt records.
- Track outstanding balances and payments.
- Record change owed to customers (monnaie à rendre).
- Search and review debt records.
- Store application data in a MySQL database.
- Provide a simple interface designed for everyday shop management.

Tech Stack

- Backend: Python, Flask
- Database: MySQL
- Frontend: HTML, CSS, JavaScript

Getting Started

Prerequisites

- Python 3
- MySQL Server
- pip

Installation

1. Clone the repository:
   
   git clone https://github.com/dioppapi/ges_dette
cd ges_btq

2. Install the required dependencies:
   
   pip install Flask mysql-connector-python
   
   Install any additional dependencies required by the project.

3. Create the MySQL database and configure the database connection in accordance with your local setup.

4. Run the application:
   
   python app.py

5. Open the local address displayed in the terminal.
